# Wallet connection and collection — 14 November 2026

The site connects through NEAR Connect 0.12.0 with an explicit directory list: Meteor, HOT, Intear, Nightly and NEAR Mobile. MyNearWallet and the legacy Wallet Selector packages are removed. Unsupported injected IDs and custom debug wallet sources cannot be selected. Available options respect the network and account-only sign-in capabilities in upstream manifests.

The shared session restores existing accounts, follows connection and sign-out events, refreshes on window focus and every 15 seconds, supports active-account selection and disconnect, and updates the marketplace. Transactions bind the reviewed active signer and configured network; an intervening account change aborts the request. The personal collection reads owner-specific onchain enumeration independently of marketplace deployment. See [wallet operations](../WALLETS.md).
